# 本地名称策略 · 2026-10-04.1

用途仅为游戏公开名称策略，不能视为完整的内容审查或法律合规清单。运行时无网络请求、无按请求费用，也不依赖上游在线服务。

## 来源与实际采用范围

- 固定来源：[houbb/sensitive-word-data](https://github.com/houbb/sensitive-word-data/tree/fe6fc2921836217b8c90619db81b24af8b22d80f)，commit `fe6fc2921836217b8c90619db81b24af8b22d80f`。
- 保留原始 [LICENSE.txt](LICENSE.txt)（Apache-2.0）和本项目 [NOTICE](NOTICE)。上游没有逐词出处清单，其仓库许可证不能额外证明全部词条来源。
- [sources.json](sources.json) 记录原文件摘要、行数、标签统计与映射依据。主 dict 为 64,419 行，deny 为空；tags 为 43,768 行。主 dict 中有 20,727 个词没有对应标签，不能把“无标签”当成“允许”或某个特定类别。
- 标签含义按固定代码来源核对：0 政治、1 毒品、2 色情、3 赌博、4 违法犯罪。一条可有多个标签，因此标签计数不能相加当作词数。
- 首版逐项筛选 **66 个中文主词库条目 + 3 个英文条目**；另有 **4 个项目规则、6 个明确变体、1 个精确例外**。全部可在 [selection.json](selection.json) 审阅。这是本次工程筛选，不代表逐项真人审核或完整覆盖。
- 没有直接启用全部上游词条。例如原主词库包含常见人名“王伟”，英文表含 `duck`、`chicken`、`gender`。普通姓名、地名与正常表达有允许语料回归；其余未采用条目保持候选状态，不据其标签自动拒绝。

## 执行规则

1. 新命名先拒绝控制字符、不可见格式字符和孤立 surrogate；再做 NFKC、首尾空格处理，检查 2—12 Unicode code point 与既有字符集。
2. 登录账号规范化单独处理。`loginHandleKey()` 仅规范化完整账号，不重新用新词库审核历史账号。
3. 保留词检查原审核串及去 `_ - ·` 的副本。副本仅用于审核，不改公开名字或密码。
4. 项目明确规则和部署 `BLOCKED_WORDS` 不受精确例外覆盖。基础规则的例外同时限定完整名字及具体规则 ID。
5. 英文条目使用 ASCII 单词边界，避免普通单词中的偶然子串。明确变体仅使用表中列出的替换，不泛化拼音、谐音或繁简转换。
6. 公开读取不套新命名长度/字符集限制。存量或 Linux.do 名称命中时使用数据库已分配的 `玩家·序号`，不覆盖原始姓名、ID、token 或成绩。
7. `name_policy_version/status` 是新命名时的记录，不是当前策略的永久批准。公共输出按当前进程加载的策略重新判断。
8. 数据包启动时做 SHA-256 和结构校验。文件缺失、损坏或结构不符时，新命名返回 `name_policy_unavailable`；存量输出使用别名，认证与游戏接口继续可用。修改磁盘词库不会热更新，需完整构建并重启应用。

## 维护与复现

修改 `selection.json` 时更新版本，写清新增、移除、匹配方式、例外理由；先补允许/拒绝测试，不自动跟踪上游 main。

```sh
# 提供已检出的固定上游源码；校验原文件摘要与条目来源后生成本地包
node scripts/build-name-policy.mjs --source /path/to/pinned-upstream

# 离线校验提交的规则与生成包一致，不访问网络
npm run check:names
node --test leaderboard/test/name-policy.test.mjs leaderboard/test/name-audit.test.mjs
```

`../name-policy-v1.js` 为生成文件，不直接编辑。发布时将规则、生成包和对应版本一并交付；回退使用完整旧版本并重新运行语料回归，不只替换部分文件。跨版本效果需结合只读扫描评估，不能据本次合成语料承诺所有误拦均已消除。

## 只读扫描

```sh
npm run ops:names -- --sqlite /path/to/existing.sqlite
```

可用于迁移前的 0004 数据库，不执行迁移或修改姓名。只输出总数、允许/替代/不可用数量、缺少别名的数量、规则 ID 计数；不输出姓名、玩家 ID、token、数据库路径。扫描结果与实际运行配置留在私有位置，不提交公开仓库。本次只对隔离数据验证此工具，生产存量扫描留到发布准备。
