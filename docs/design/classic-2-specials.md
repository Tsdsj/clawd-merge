# classic-2 特殊掉落与后期目标设计

日期：2026-10-12。状态：已实现（见 §9），设计已获用户确认（方向 B+D、三只特殊Clawd 全上、王冠与抉择全上、经典直接进化、历史榜不重置、每日暂不同步）。

范围：经典模式新增三类特殊掉落（金色/磁力/冰冻Clawd）与两项后期目标（王冠信物、升天抉择）。每日挑战保持 `daily-1`；经典榜单不重置、不迁移。本文是规则与接口设计，不含实现承诺。

## 1. 规则版本与兼容

- `src/rules.js` 新增 `classic-2`；新对局一律 `classic-2`，进行中的 `classic-1` 存档按 `classic-1` 规则打完，不得中途换规则。
- `Game` 按存档 `rulesVersion` 参数化规则集（掉落序列、特殊规则、王冠/抉择开关）。`save-store.js` 接受受支持版本列表（`classic-1`、`classic-2`），restore 时按存档版本选择规则集；新局记录为 `classic-2`，恢复的 `classic-1` 局继续按原版本保存。
- 快照 `SCHEMA_VERSION` 保持 1。`classic-2` 快照新增可选字段：`current`/`next` 与 bodies 的特殊编码、王冠计数；`classic-1` 快照校验与恢复行为不变。
- 持久化取舍：
  - 金色无时限，其特殊标记随快照持久化，直到参与一次合成后耗尽。
  - 磁力/冰冻生效窗口（2.5s/3s）不持久化，恢复时视为已过期，载体普通化，保证恢复确定性。
  - 升天抉择挂起状态不持久化：快照仍保留两只未消耗的大Clawd 与接触，恢复后首次检测到接触会重新弹出抉择，由玩家重新选择，不自动结算。

## 2. 特殊掉落总纲

- 单一「特殊位」掷骰取代彩虹独立掷骰：自第 12 投起，单次投放约 6% 概率成为特殊位（精确阈值模拟调参后定稿）。
- 池内权重草案：彩虹 40 / 金色 25 / 磁力 20 / 冰冻 15。
- 防连规则：不连续出特殊；同类特殊 25 投冷却；磁力/冰冻同屏各最多 1 个生效中。
- 编码：三只特殊均以 1–5 级普通Clawd 为载体（等级 + `special` 字段），保留既有碰撞体与合成资格；彩虹维持 `level 0` 既有编码。`challenge.js` 序列生成不读特殊规则，`daily-1` 不变。

## 3. 三只特殊Clawd

| | 金色 | 磁力 | 冰冻 |
| --- | --- | --- | --- |
| 触发 | 特殊位抽中，随机 1–5 级 | 同左 | 同左 |
| 效果 | 参与的那次合成基础分 ×2 | 落地后 2.5 秒吸附半径内同级 | 落地冻结接触到的一堆 3 秒 |
| 结束 | 参与一次合成后金光耗尽 | 与同级合成成功或超时后普通化，两种结束都算正常合成 | 超时解冻；被冻Clawd仍可被投下的同级正常合成 |
| 边界 | 与连击/狂热乘法叠加，单次最高 ×8 | 向心吸附、限制吸力带来的接近速度，移动经过完整碰撞求解，不拽穿接触对 | 冻结不解救危险线判定；冻结期间速度清零、接触保持，独立冻结约束阻止普通唤醒，同级合成仍可消费冻结体 |

磁力与冰冻是互补的「拉」与「锁」：都不直接给分，只帮规划型玩家完成合成；金色是唯一的分数修饰。

## 4. 王冠信物与升天抉择

**王冠信物**：HUD 三顶王冠进度，每次升天 +1；集满 3 顶触发全屏庆典 +5000 分，进度清零，可无限循环。不做场上实体（不占空间、不进物理），纯 HUD 与特效。

**升天抉择**：两只 11 级接触合体时暂停并弹出双按钮：

- **升天**：现有 +2000，王冠 +1（既有行为）。
- **王冠清扫**：两只大Clawd 化作冲击波消散，清掉全场 ≤2 级，零得分、王冠不进。

防退化关键：两条路都消耗这对大Clawd，不存在「清扫后再留着拿分」的严格优势解。真取舍 = 2000 分 + 进度 vs 残局救命。

## 5. 服务端与榜单

- 榜单不重置、不迁移；`classic-2` 成绩照常走现有提交、回执、幂等与最佳成绩条件更新链路，服务端无必须变更。
- 服务端「耗时×分数」合理性校验需按 `classic-2` 分数上限复核；若现有阈值会拒绝合法新高分，调整阈值属服务端变更，需另行记录并先于前端发布。
- 升天抉择不改变对局凭证流：仍是一次连续对局，不新增局中断点。

## 6. 表现与图鉴

- 图鉴新增「特殊篇」3 条目（金色/磁力/冰冻），解锁卡片复用现有首次发现机制；图鉴隔离规则沿用（挑战不持久化经典偏好）。
- 像素画沿用 ASCII 字符画与栅格化缓存；金色为色调叠层，磁铁/冰泡为绘制层，不新增碰撞圆。
- 音效沿用 WebAudio 实时合成：合成音高体系不变，金色加倍音、王冠庆典琶音、磁力嗡鸣、冰冻碎裂各一个新音色。

## 7. 平衡与验证

- 模拟玩家重跑：沿用 README 四类模拟玩家口径，调参对象为特殊位概率、池内权重、磁力半径/力度、冻结时长。验收线：同点与随机玩家均分涨幅 < 20%，规划玩家（找同级/预判落点）上限明显抬高。
- 新增测试：`classic-2` 序列版本与固定向量；金色双倍计分与 ×8 叠加上限；磁力仅窗口内、仅同级的力；冻结不阻断被合成；王冠循环与 +5000；抉择双路径与消耗性；`classic-1` 存档按旧规则打完且不出现特殊位；快照编码与恢复确定性（磁力/冰冻过期、金色持久、抉择默认升天）。
- 原型先行：掉落表现、抉择弹窗、王冠 HUD 先出可点击原型（`docs/prototypes/` 惯例），经确认后实现。
- 发布顺序：如需调整服务端阈值，先服务端后前端；其余为纯前端发布。

## 8. 非目标

不做独立新入口、不重置或拆分经典榜单、不改每日挑战、不做货币/商店/付费、不做新特殊外观奖励、不修改物理求解器稳定性参数、不承诺跨设备逐帧一致回放。

## 9. 实施结果（2026-10-12）

- 规则与掉落：`src/rules.js` 新增 `classic-2` 常量与 `chooseClassicDrop` 单点分发；新局默认 `classic-2`，`classic-1` 存档按旧规则打完并可继续保存；挑战不接特殊。
- 快照：新增 `currentSpecial/nextSpecial/specialLastAt` 与 body `special`；金色持久、磁力/冰冻恢复即过期、抉择挂起不持久化（恢复后重新弹）；冷却锚点持久化保证恢复确定性。
- 特殊与后期目标：金色单次合成基础分 ×2（与连击/狂热叠至 ×8）、磁力 2.5s 同级吸附、冰冻 3s 连通堆冻结；双王触发升天抉择，王冠满 3 顶循环 +5000；`classic-1`/挑战保持自动升天。
- 平衡：模拟调参定稿 `chance 0.08`、`weights 彩虹 44 / 金色 24 / 磁力 19 / 冰冻 13`（彩虹命中率 3.52%，与 classic-1 的 3.5% 持平）。150 局/策略：同点 +12%、随机 -11%、找同级 +14%（最高分 31424 vs 20710，+52%）。
- 服务端 §5 复核：`POST /api/score` 仅有耗时×分数合理性校验（`score > drops*400 + 5000`）与 `score ≤ 10^7` 硬上限；调参后合法高分（模拟最高 31424）远低于阈值，**服务端无变更，纯前端发布**。每日挑战的同类校验不涉及。
- 发布：2026-10-12 已发布至生产（提交 `220b0edb8768ffb30d2b26a3793f70d3325bccac`），发布证据与回退说明见 [classic-2 发布记录](../verification/classic-2-release.md)；手机真机项待补。
