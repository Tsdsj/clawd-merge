## 入口与布局

保留经典和每日现有 ? 按钮，访问名称改为“玩法与舒适设置”。打开后默认展示当前模式的玩法，提供“舒适设置”页签；不增加一排新的棋盘按钮。原型上的“打开舒适设置”是审查快捷入口，不进入产品。

桌面是居中的窄弹窗，手机仍为同一弹窗。标题、页签和底部完成按钮保持可见，中间内容独立滚动。320px 窄屏保留三段动态选择，开关触控区域至少 44×44。原型使用 native dialog，Esc/关闭/完成均退出；返回触发入口，保留原暂停原因，不自动解除用户手动暂停。正式挑战绝对提交截止继续流逝。

只用轻量状态反馈，不引入拖拽、弹跳抽屉或新的手势体系。原型审查控件不进入产品；要切换外部场景先关闭弹窗，也可在弹窗底部用“模拟系统偏好变化”“模拟刷新设置”检查状态转移。

## 已确定的默认值

| 设置 | 默认 | 语义 |
| --- | --- | --- |
| 动态效果 | 跟随系统 | 在系统偏好为 reduce 时使用减弱动态；系统变化即时更新有效状态 |
| 合成震屏 | 开 | 记忆用户选择；只有有效模式为标准时启用 |
| 装饰粒子 | 开 | 记忆用户选择；只有有效模式为标准时启用 |
| 触控震动 | **关** | 独立于动态模式，只有用户开启、设备提供能力且发生有效触控后才允许请求 |
| 音效 | 沿用原设置 | 不挪入本设置，不随恢复默认而改变 |

“触控震动默认关”是本次明确选择：现有 M2 是有效触控后按设备能力尝试震动，后续接线需将首次舒适设置的默认值设为关闭，不应误以为已有 hapticsReady 标记是用户开启偏好。

动态模式有三项：

- **跟随系统**：随系统变化，并展示“当前系统：标准/减弱 · 已跟随”。
- **减弱**：始终减弱，不因系统切换重新开启。
- **标准**：用户显式选择标准，显示“不随系统变化”；震屏和粒子仍受各自开关控制。

减弱动态生效时，震屏与装饰粒子显示关闭并禁用，下面说明“原开关选择保留”。退出减弱后恢复记忆中的值，不能把临时有效值反写成用户偏好。触控震动是独立开关，不随视觉模式强制改值；当前设备缺少能力时禁用操作并说明，不因不支持而删除已保存偏好。

## 显示效果边界

| 项目 | 标准 | 减弱 |
| --- | --- | --- |
| 棋盘震屏 | 按独立偏好 | 关闭 |
| 合成/庆祝装饰粒子 | 按独立偏好 | 不创建 |
| 弹跳、强烈庆祝闪动、装饰缩放/位移 | 沿用标准效果 | 静态或无运动替代 |
| 危险线、分数、投放剩余、道具反馈 | 保留 | 保留清晰的静态反馈；不能把危险提示一起隐藏 |
| 碰撞、落下与合成过程 | 不变 | 不变；属于核心玩法而非装饰 |
| 物理子步、概率、计分、道具、正式资格 | 不变 | 不变 |

效果预览仅在点击时播放一次，最长约 650ms；不自动循环、不计分、不发声、不震动。真实实现可调用独立效果预览，不能借用当前 Game 触发真实合成、进度或奖励。

## 保存、恢复和异常

选择立即作用于本页，并尝试保存到本机；无需“保存并退出”按钮。经典与每日共用，同一浏览器 origin 下的不同账号也共用，不把这类设备偏好同步为账号权益。

- **保存成功**：显示“已保存到本机 · 即时生效”。关闭/再打开保留选择。
- **写入失败**：保留本页有效设置，显示“未能保存。设置已在本页生效，刷新后可能恢复旧设置。”提供重试，不能回滚游戏或冒充保存成功。
- **读取失败**：使用安全的默认设置并提示，保留原存储记录，不自动清空或覆盖。没有手动编辑时重试读取；有本页手动编辑后不得把迟到的旧值覆盖回来。
- **恢复默认**：立即恢复 system / shake=true / particles=true / haptics=false，并尝试持久化。提供一次“撤销”；后续手动改动清除撤销入口。撤销只还原本次默认操作之前的舒适设置，不修改音效、图鉴、游戏存档、身份或成绩。
- **焦点**：撤销后回到恢复默认按钮，重试成功后到完成按钮；不让焦点停在已隐藏的控件上。输入使用原生 radio/switch，键盘可操作。
- **跨页与版本**：M3-02 需要处理 storage 事件和字段校验。初始读取、系统变化和其他页面通知不触发无意义的回写；保存未知版本/损坏数据时不自动清空。具体恢复逻辑须有测试，不以原型内存演示代替。

## M3-02/03 接口约束

建议单独本机 key `clawd-merge:comfort`，值结构固定为：

```json
{"schemaVersion":1,"motion":"system","shake":true,"particles":true,"haptics":false}
```

不保存账号、API 目标、游戏状态、规则版本或媒体查询的即时结果。设置 schema 版本与游戏规则/存档版本独立。模块同时暴露“用户偏好”“当前有效效果”“保存状态”，避免 UI 和 Game 分别推导出不一致结果。

有效值规则：`reduced = motion === "reduced" || (motion === "system" && systemReduced)`；`shake = storedShake && !reduced`；`particles = storedParticles && !reduced`；强化装饰动效在 reduced 时关闭。haptics 的能力/触控约束单独处理。无法检测系统偏好时提供明确的保守降级，不影响游戏可玩性；该异常不是已在本原型模拟的设备状态。

M3-02 实现设置模型/校验/保存与变化通知；M3-03 才接共享弹窗、两个模式和特效消费者。本轮没有更改 `src/`、`index.html` 或线上产品。
