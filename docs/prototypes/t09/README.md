## 用户已确认的规则

- 游客与 LINUX DO 用户都能正式挑战；未建立身份时可直接练习，正式挑战先选择游客或 LINUX DO。
- 北京时间每日 00:00 换题，同题同序列，100 次投放。
- 每身份每日 3 次正式机会，练习不限次数。
- 最后一投后最多结算 8 秒，落稳可提前结束。
- 跨日旧题允许提交到次日 00:10。当前对局不换题，也不挪入新一天的榜单。
- 这些默认值先用于原型与试玩，再按明确版本调整，不静默修改已发布的题目。

## 信息结构与拟定交互

经典模式仍为产品默认入口，标题下增加“经典模式／每日挑战”切换。每日入口呈现题目日期、投放总数、正式机会、个人最好和两个明确按钮。查看入口不扣机会，领取正式凭证成功后才扣 1 次。

正常路径：每日入口 → 开局确认 → 正式对局 → 最后一投／危险线结束 → 独立结果 → 再挑战／练习／今日榜。正式与练习在对局顶部、结果页都持续标注；剩余投放与分数并列。

拟定的存档行为：经典与挑战各保留一局，切到经典时保留未完成挑战。挑战内部正式与练习共用一份挑战存档；开启练习替换未完成正式局前必须确认，不能自动抹掉资格或退还已用机会。已有挑战时入口优先“继续原局”，不再扣次。

## 结算细节（本次原型推荐）

- 第 100 次投放后立即停止新投放和道具输入，“下一个”改为“已投完”。进入有限结算，禁止主动新开或切模式打断结算。
- 推荐落稳定义：所有刚体休眠、没有新合成，连续 0.75 秒；否则最多运行 8 秒游戏时间。危险线提前满足原失败条件时立即结束，不等待满 8 秒。
- 系统切后台仍遵守 M1 暂停保护，回来继续剩余结算时间；服务端绝对提交截止不会随暂停延长。此处不新增“暂停可延长正式资格”的承诺。
- 正式结果进入挑战专用上传／回执流，不能调用经典成绩接口冒充正式成功。服务端已接受后的回执重放可以在截止后确认；未接受的逾期请求不得依赖客户端自报结束时间补入正式榜。

## 关键异常状态

| 状态 | 原型中的行为 |
| --- | --- |
| 今日题目加载 | 显示加载说明，正式与练习按钮暂不可点；仍可回经典 |
| 获取失败 | 不扣机会；可重试；有缓存时仅可练习那道已缓存题，无缓存时回经典 |
| 今日机会用完 | 正式按钮禁用；不限次练习保持可用 |
| 恢复核验失败 | 保留原局，重试不领新凭证；允许明确转练习，转后本局不恢复正式资格 |
| 跨日进行中 | 持续标注旧题与 00:10 提交截止，不替换棋盘 |
| 截止已过 | 停在资格提示，明确选择转练习后继续，不继续冒充正式 |
| 断网结算 | 结果页显示暂存与提交截止，重试独立于新局；不保证未及时到达服务端的成绩仍可上榜 |
| 未完成正式局改练习 | 先确认放弃，已用机会不退回；经典存档保留 |

游客每日次数按服务端身份统计。重建游客身份可能绕过单身份次数，这是 T10 的限流与滥用控制边界，不宣称强防作弊。

## T09 与 T10 的实施边界
