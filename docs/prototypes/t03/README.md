# T03 直接开玩与轻量引导：设计稿

日期：2026-10-02。状态：用户已确认，正式实现已在本地接入；本目录保留为独立设计依据。

## 查看方式

在仓库根目录运行 `npm start`，打开 `http://localhost:5173/docs/prototypes/t03/`。本轮预览使用端口 5174，可直接访问 `http://localhost:5174/docs/prototypes/t03/`。

`index.html` 是独立可点击原型，仅复用 `src/crabs.js` 绘制现有像素角色，不加载 main/game/leaderboard，不读写账号或游戏存档，不发送 API 请求。左侧／顶部场景选择器是评审工具，不属于游戏界面。

## 设计方案

首屏直接露出棋盘，首次操作无登录门槛；顶部保留“加入排行榜”与榜单入口。本地局持续标注“成绩仅保存在本机”。原来的钳子、音效和重开入口保留，补充玩法说明入口。手机上操作按钮另成一行，避免分数和“下一个”挤压换行。

新手提示放在棋盘外，避免遮挡投放及堆叠区域，首次投放后依次说明合成、下一只及危险线。玩家可随时关闭；正式实现按浏览器记住已完成的引导，不每局重放。已有账号不重复首次引导。特殊道具说明只在首次获得／出现时提示，本原型未模拟完整道具过程。

本地局结算保留“再来一局”为主按钮；次要入口是“加入排行榜，下局见”。明确当前局不参与排名、不能补交，避免身份选择成为结算阻断。

加入弹窗保留 LINUX DO 和游客两条路径，始终可以关闭或“先继续玩”。局中选择外部登录时需提示会离开当前页面，推荐打完后再加入；T03 不承诺续玩（T05）或补交（T06）。正式实现中切换身份不得改变已开始本地局的上榜资格，下一局才使用新身份凭证。

服务不可用显示非阻断提示，仍可投放；原型中的弱网为展示场景，不代表真实断网验证。已有账号只有在拿到当前局的有效凭证后才显示“本局参与排名”；请求中／失败时不能提前承诺上榜。

## 原型操作与限制

- 六个场景：首次进入、投放后、本地结算、服务不可用、已有账号、加入排行榜。
- 点棋盘可演示提示切换，点“再来一局”可回到无引导的新局展示。
- 身份弹窗、玩法说明支持关闭与 Escape，浏览器原生 dialog 管理焦点；游客名支持最小长度反馈。
- 图像直接复用现有像素素材，深蓝底、暖橙主色沿用现有主题；没有新增 UI 库。
- 分数、棋盘和昵称均为示例；没有实际物理、拖动、方向键瞄准或声音播放。页面上的操作文案描述正式游戏行为。原型音效按钮只切换演示状态。
- 原型外壳允许滚动以查看评审场景；正式游戏继续沿用自适应棋盘，不将评审外壳计入屏幕高度。

## 浏览器检查

已检查桌面场景、390px 与 320px 窄屏；首次投放、结算打开身份选择、关闭后再来一局、弱网场景可操作。检查过程中修正了窄屏 HUD 文案挤压问题，原型控制台未发现 warning/error。

这些是原型交互与排版证据，不是正式业务或移动真机验收。未执行真实登录、账号创建或线上成绩提交。

## 确认与实施

用户已确认首屏、引导位置、登录入口与本地结算流程，以及“未登录本局不上榜，加入后下一局参与排名”的规则。T03 已本地实现；暂停、断点续玩和可靠补传继续按 T04—T06 推进。正式界面将身份与局状态放在同一行以节省棋盘空间；小窗口仍保持按钮独立一行。
