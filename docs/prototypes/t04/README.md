# T04 暂停与重开保护

日期：2026-10-02。状态：用户已确认；本地正式实现已接入。本目录作为独立设计依据保留。

运行仓库的静态服务器后，打开 `/docs/prototypes/t04/`。本轮地址为 `http://localhost:5174/docs/prototypes/t04/`。

本原型沿用正式样式和像素角色，加入暂停／继续与重开确认。棋盘、分数及榜单均为示例，不读写存档，不发起账号或成绩请求。顶部场景按钮与“模拟运行时间”仅供评审，不进入正式产品。

## 交互规则

| 触发 | 页面反馈 | 恢复规则 |
| --- | --- | --- |
| 暂停按钮或 P | 棋盘变暗，显示“已暂停”和“继续游戏” | 点击继续或 P |
| 切到后台，再返回 | 显示“欢迎回来”，不自行恢复 | 点击继续或 P；没有倒数等待 |
| 进行中打开排行榜、账号、身份选择或玩法说明 | 弹窗期间冻结游戏 | 关闭后恢复原状态 |
| 手动暂停时打开排行榜 | 弹窗显示在暂停层之上 | 关闭后仍为手动暂停 |
| 弹窗期间切后台 | 保留弹窗，记住后台暂停 | 关闭弹窗后显示“欢迎回来”，需要继续 |
| 已投放的未结束对局重开，或按 R | 弹出确认，默认焦点在“保留这局” | 取消回到原状态；确认后清空棋盘开启新局 |
| 空局或已结束对局重开 | 不弹确认 | 直接开始新局 |

重开确认文案：当前这局还没结束，重新开始会清空棋盘和本局分数；本机最高分和已解锁图鉴保留。操作为“保留这局”和“放弃本局，重新开始”。Escape 等同取消，不能确认重开。

暂停不等于存档。界面不承诺刷新、关闭页面或系统回收后仍可继续；该能力属于 T05。暂停期间服务端凭证的真实有效期仍继续流逝，沿用现有到期处理，不通过暂停延长在线上榜资格。

## 正式实现约束

- 用暂停原因集合管理状态，至少区分手动、后台与弹窗。关闭一个原因不能解除其他原因。
- 暂停物理、游戏计时、危险倒计时、狂热、投放冷却及效果时间；可以继续渲染静态画面。
- 进入暂停／失焦时清除方向键、拖动与待执行投放；继续不会自动补投。恢复时清空帧时间累积，不补跑后台经过的时间。
- window 失焦也要保护进行中的操作，避免方向键 keyup 丢失；重新聚焦不自动续局。
- 暂停／继续不重置棋盘、不新建上榜凭证。只有真正重开才开始新局并申请新凭证。
- 结算不出现“继续游戏”；新局清理旧暂停原因和旧结算异步状态。
- 保留焦点管理和小屏滚动；原生 dialog 的示例交互在正式实现中可复用已有弹窗组件。

## 验收重点

危险线倒计时和狂热期间打开弹窗，关闭后数值不减少；手动暂停→查看榜单→关闭仍暂停；弹窗中切后台→返回→关闭仍需继续；按住方向键或拖动时切走，回来后不漂移、不投放；R 与按钮重开行为一致；取消重开保留全部游戏状态；确认重开仅保留最高分、图鉴与账号。

原型用“模拟运行时间”展示暂停与恢复，不包含真实物理或游戏倒计时。正式数值验收在设计确认、实施后完成。
