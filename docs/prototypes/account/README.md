# A02 · 账号流程原型（待设计确认）

依据：[A00 账号契约](../../design/account-contract.md)、[账号开发计划](../../account-system-plan.md)。

这是隔离的可点击设计稿，未接 API、OAuth、密码验证或存储。所有名字、编号、成绩和恢复码均为虚构演示数据；输入只停留在当前页面，不写入本机存储。原型中的“成功”不代表创建了真实账号。

## 查看

从项目根目录启动现有 `npm start`，打开 `/docs/prototypes/account/index.html`。也可通过独立静态服务器查看。不要直接用 file 协议打开，因为原型引用现有像素 Clawd 模块。

- 选择“审查场景”立即打开对应界面；关闭面板后可切换场景、当前对局、原本暂停状态。
- “线框结构”用于检查信息结构；高保真沿用现有背景、橙色按钮、字体和像素角色。
- `?scene=entry`、`?scene=linked` 等参数可直达场景。30 个直接场景，加上表单校验、倒计时和 OAuth 演示结果。
- 完成注册示例：创建密码账号 → 填名字 → 获取完整账号 → 输入两次至少 15 字符的演示密码 → 保存信息 → 返回游戏。请勿在原型中输入真实密码。

## 结构与操作

| 入口                | 用户路径                                              | 关键约束                                                       |
| ------------------- | ----------------------------------------------------- | -------------------------------------------------------------- |
| 加入排行榜          | 登录 / 注册 / Linux.do / 游客 / 本地继续              | 本地玩无需创建账号；账号保存成绩，不同步棋盘                   |
| 注册、游客设密      | 选名字 → 确认完整账号 → 设密 → 保存恢复码             | 完整账号在提交密码前可复制；游客原地升级                       |
| 登录                | 完整账号 + 密码 → 原局检查 → 账号                     | 不查询同名列表；缺编号在本地提示；密码允许粘贴                 |
| 恢复                | 恢复码或 Linux.do 新验证 → 新密码 → 新恢复码          | 不凭分数或截图找回；没有恢复方式时直说无法恢复                 |
| 账号管理            | 固定登录账号、公开昵称、两种登录方式、恢复码          | 四种身份显示各自能力；Linux.do-only 设置本地账号前跟随外部名字 |
| 绑定                | 验证当前密码 → 说明保留信息 → OAuth 演示 → 双方式账号 | 正式账号冲突不合并，不泄露对方资料，不提供解绑                 |
| 游客进入旧 Linux.do | OAuth 演示 → 对局检查 → 旧账号                        | 合并只适用于游客；游戏归属仍需正式接线保护                     |
| 改昵称              | 输入新昵称 → 账号面板                                 | 固定登录账号不变；公开编号可能重新分配                         |
| 改密 / 更换恢复码   | 再次验证 → 保存新的恢复信息                           | 旧码不重新展示；更换后失效                                     |

当前保留单面板逐步切换，避免多个对话框叠加。窄屏正文独立滚动，头部关闭和设计标记保持可见；操作按钮随正文，不能覆盖表单或错误提示。

## 异常与游戏归属

- **账号或密码错误**：统一错误，不透露账号是否存在。
- **限流**：展示 30 秒演示倒计时，结束后可提交。正式倒计时来自 Retry-After。
- **请求中**：可取消；演示等待后进入超时。取消清除延迟页面更新。
- **注册结果未知**：检查同一次操作结果，不提供盲目再次注册。回执过期后用完整账号登录或恢复。
- **注册准备保存失败**：提交密码前要求用户另存完整账号并明确确认临时继续。
- **登录状态保存失败**：明确“本页可用、刷新后需重新登录”；保留账号与恢复码复制、保存确认及重试入口。
- **名称不可用 / 密码入口暂不可用**：可改名或继续本地玩；原型不包含实际敏感词审核。
- **切换账号**：经典在线局可明确转为本地；每日未完成、开局未知和待上传记录阻止直接切换，返回原游戏处理。
- **同账号设密**：通常保留原局；待上传场景先回游戏处理。正式实现需准确区分请求进行中与已安全落盘的队列，不能据本原型推断并发正确性。
- **暂停与键盘**：原生 dialog 限制焦点，Escape 关闭、返回入口焦点；恢复打开前的暂停状态。演示没有真实投放键盘监听或每日时钟。

## 原型验证记录（2026-10-04）

- 隔离 Chromium：30 个直接场景 × 5 类视口（320×740、390×844、1280×900、844×390、390×380），150 组检查无横向溢出，面板保持视口内，运行时 pageerror 为零。390×380 仅模拟键盘挤压后的可用空间，不代表真机键盘验收。
- 注册、完整账号提示、两次密码校验、可见切换、保存确认、恢复、新密码、绑定冲突、每日切换阻断、经典转本地、存储重试和取消等待均走过可点击流程。
- 正向及反向 Tab 循环、Enter 提交、Escape、关闭回焦与原暂停状态已检查；发现原生焦点循环边界问题后增加显式首尾循环，并回归通过。未保存恢复信息的关闭提醒、返回保存与明确放弃关闭，以及 30 秒限流倒计时均已验证。
- 已配置 username/current-password/new-password 自动填充语义；未验证实际密码管理器、真机输入法、Safari、真实剪贴板限制或真实游戏快捷键。
- 高保真 PNG 已逐张检查主要内容。仅新增 docs 原型与规划状态，未改业务代码、数据迁移、部署或运行配置，不重跑无关业务回归。
