# 自托管迁移验证摘要

本文件只保留通用实现与验证结论，不包含实际域名、服务器地址、账户、密钥、数据库数据或实例巡检信息。完整部署参数和证据在本机私有交接记录中维护。

## 交付

- Compose统一管理Node API、Nginx、Certbot和SQLite备份任务；SQLite数据使用持久化挂载，API无公网端口。
- 前端运行配置与旧站迁移地址从部署环境生成，不入Git。仓库本地默认单机运行，loopback调试能力保留。
- SQLite适配器识别导入的D1迁移历史，事务失败回滚，进程重启不重复执行schema变更。
- 旧域名提供浏览器数据搬家入口：明确确认、校验来源/窗口/nonce、限定生产数据集、不覆盖冲突账号/存档、写失败回退，原数据保留。
- 旧API只作过渡转发，旧D1退出在线读写路径；新站前端、API、OAuth回调和数据库均在自托管环境运行。旧资源暂留兼容/回退，不视为已经永久删除。

## 已验证

- 本地181项回归通过，发布提交的CI通过；真实HTTP超时与隔离workerd/D1兼容回归通过。
- 生产Node容器在隔离副本中完成经典成绩八次重放只计一局、挑战开局八次重放只扣一次机会。
- 冻结旧写入后，最终导出完整性正常；目标全部业务表的行数与内容摘要与源快照一致。
- 线上静态资源逐文件摘要一致；HTTPS证书与续期dry-run通过，私有API/配置没有被当作静态文件公开。
- 主机重启后四个Compose服务自动恢复，API健康；在线SQLite备份完整性检查通过，另保留了受限的离线副本。
- 真实浏览器完成原Linux.do账号登录，进入经典排名资格；每日挑战读取当日题目与机会，未为验收额外消耗正式机会。
- 匿名经典实玩触发合成/计分，暂停和刷新恢复通过；320px布局通过。页脚文字继承图标宽度的问题已修正。
- 两个隔离浏览器来源之间实际完成样本身份和本机纪录传输；旧入口部署成功，新站正常访问。
- 提交前检查未发现实际部署地址、本机私有路径或OAuth Secret进入新增内容；原硬编码Cloudflare部署值已改为开发模板。

## 边界

这是现有功能的基础设施迁移，不是用户名密码功能交付。A01缺陷修复与A02—A06账号开发仍沿原计划推进。

没有宣称经过手机真机、各运营商晚高峰、大规模并发或长时稳定性验收。自动备份目前是同机备份加本次离线副本，持续异机备份需另行配置已授权目标。退役过渡入口时应先处理旧标签页与玩家本机数据，不直接删除唯一副本。
