## 生产协议与数据隔离

使用新建的专用测试游客，提交的是 **0 分协议样例，不是实玩正式成绩**。

- 健康检查、游戏 origin CORS、匿名题目读取正常，匿名原凭证核验返回 401。
- 同一开局标识并发请求 3 次，返回同一凭证，只扣 1 次机会；核验状态为 valid。
- 同一 0 分成绩并发提交 3 次，返回同一回执，best=0、rank=null；改内容返回 409，经典接口拒绝挑战 payload。
- 接受后原凭证为 used；重放开局仍返回 used，不重新开一局。
- 再并发请求 3 个不同开局标识，仅 2 个成功，另一个 attempts_exhausted；最终 used=3、remaining=0。
- 该身份没有进入公开榜单。生产 D1 精确核对：凭证 3、0 分接受记录 1、挑战最佳榜记录 0、经典成绩 0、经典 games=0。
- 仅按本次生成的精确 player ID 清理对应成绩、回执、凭证、次数、token、测试限流记录和身份，核对剩余玩家/凭证/接受记录均为 0；不清理其他用户或已有运行维护候选。已移除本机临时 token 文件。
- 当日公共题目定义保留，供真实玩家继续使用。未删除新表或其他玩家数据。

## 真人补验清单

建议在手机浏览器打开上方正式地址，按以下顺序做一次即可；结果可按项目回报“通过/失败 + 设备浏览器 + 出错步骤”，不要提供 token、登录码或其他账号秘密。

- [ ] 从每日入口先登录真实 LINUX DO，完成授权回跳，确认昵称正确、题目日期与剩余次数可见。
- [ ] 开始一次正式挑战（会消耗今天 1 次机会），投放若干次后暂停、切换到其他 App 再回来；原分数/剩余投放保留且不会自动继续落子。刷新后核验并恢复原局，正式次数不额外减少。
- [ ] 完成该局，确认服务端接受结果与本题榜/个人结果一致；不需要刻意制造高分或重建身份。
- [ ] 打开分享卡：系统分享面板可打开并取消，不提示已发送；保存 PNG 后可在设备中打开。用另一浏览器打开复制出的同题链接，确认题目正确、打开不扣次数且不会覆盖已有局。
- [ ] 手机竖屏/横屏均可操作，关键按钮和剩余投放没有被遮挡。若系统长期回收页面导致异常，记录持续时间与恢复状态，不能凭短时切后台替代长期回收测试。
