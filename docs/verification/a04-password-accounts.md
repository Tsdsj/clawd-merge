# A04 · 密码账号完整切片

日期：2026-10-04。状态：实现与工程验证完成；未部署、未执行生产迁移。A05 的新增 Linux.do 绑定与近期授权入口保持关闭。

## 交付

- 注册、游客原 ID 升级、完整账号登录、改密、恢复码找回和验证后轮换恢复码；公开昵称与固定登录账号独立。改密撤销旧会话，但保留原恢复码；找回会轮换恢复码。
- Node 原生异步 scrypt：N=32768、r=8、p=3、32 字节输出、maxmem=48 MiB；最多两个并发，繁忙立即返回可重试状态。哈希不占数据库事务，提交前重新验证身份与凭据版本。
- `0006_password_operations.sql` 增量迁移，0001—0005 未修改。签名操作票据、UUIDv7 十分钟期限、payload HMAC、AES-GCM 回执、数据库原子写入、结果查询及取消未完成意图。
- 统一 token 到期与版本检查，撤销旧 token/操作，保护旧 OAuth 合并和兑换。正式密码账号不会被旧游客合并吞并；OAuth 回跳和存储重试不能覆盖另一标签页新身份。
- 采用已确认 A02 账号面板，加入保存失败确认、内存登录、恢复信息确认、超时查原结果、跨页身份变化提示。相同玩家改密保持棋盘和原局凭证，补传遇到旧 token 失败会使用当前身份重试。
- 私有 keyring 生成器拒绝源码目录和覆盖，文件 0600；默认关闭密码服务，发布时才引入 `deploy/compose.password.yaml`。密钥不写日志或 Git。
- 运维报告扩展过期 token/grant/reservation 与回执清理 SQL 预览，每批至多 500 行；回执先脱敏为 tombstone，24 小时后可删除。未创建定时任务或执行真实数据清理。
