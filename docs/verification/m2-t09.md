## 已交付

- 默认仍为经典模式；通过模式切换进入每日挑战。经典与挑战各用一个 Game／Canvas，暂停、输入与计分互不混用。
- 100 次预生成掉落，使用 T08 `daily-1`，不根据玩家最高等级改变公共序列。当前练习题从本机北京时间推导，界面明确标注，不冒充服务器题目。
- 最后一投后 current／next 为空，不生成第 101 只；停止投放与道具输入。所有刚体休眠且无新合成持续 0.75 秒后结束，最长 8 秒游戏时间；危险线失败可更早结束。
- 排队等待冷却的第 100 投从实际投放后开始结算计时。暂停冻结结算，恢复／刷新保留剩余计时；完成事件幂等，不重放得分或奖励。
- 独立练习结果页、同题再练、返回入口、已完成结果刷新后重新查看。
- 挑战存档键为 `clawd-merge:save:daily:<API scope>`，沿用 Web Locks／BroadcastChannel 单写入者协议。经典存档键与格式保持兼容，明确拒收挑战快照。
- 新挑战先成功保存再替换内存旧局；坏档需要确认替换，失败写入保留原记录。存储或互斥不可用时，须明确选择临时练习，不覆盖旧档。
- 挑战不改写经典最高分、图鉴或成绩上传队列；本地练习不调用任何成绩接口。
- 竖屏沿用确认设计；横屏将 HUD 与操作放在棋盘侧边，给同一个 400×640 逻辑场地留出高度。布局缩放不改变物理规则。
