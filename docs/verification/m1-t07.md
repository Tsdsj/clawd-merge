## 性能基线

设备：Apple M5 Pro，48 GiB 内存；Codex 内置 Chromium 154。工具 UA 中的 Intel/macOS 10_15_7 是浏览器兼容字符串，不是实际 CPU 型号。

入口：[test/performance.html](../../test/performance.html)，先运行 `npm start` 再打开 `/test/performance.html`，点击“运行三种场景”。页面不接入排行榜和存档，音效仅在测试文档中静音，不改偏好。每场景预热 60 帧、采样 300 帧，种子 20261002，模拟步长固定 1/60 秒。测量 JS update/render 调用耗时；rAF 间隔另记。全量数字显示在页面 JSON 中。

满盘每 30 帧补回 60 只；连续合成每 4 帧加入一对，并在超过 60 只时清空棋盘。为持续采样，重置危险计时。这些是固定合成负载，包含真实物理求解、合成与特效，但不是正常游玩录像。场景维护耗时与 update/render 分开测；不包含浏览器异步 GPU 合成、主界面 DOM、音频与保存。`framesWithScoreIncrease` 含预热共 360 帧；其他统计仅含 300 帧采样。
