## 交付

- 每日挑战结果可打开真实 Canvas 分享卡，PNG 900×1200；卡片包含本局分数、原玩家昵称、最高 Clawd、投放次数、原题日期、规则版本、完整同题链接。
- 正式已提交状态只使用本局匹配的接受回执。待提交、已移除/被拒绝未确认、练习有各自标记；不输出名次或身份凭据。
- 按文件分享能力提供系统分享；取消不报成功。保存 PNG、图片预览长按/右键保存、复制链接、选中文本手动复制作为降级。图片使用本地像素资产，不依赖头像、图片托管或新生产依赖。
- 分享 URL 从固定公开产品地址构造，只含题目、版本、目标分，不继承本地 API override、token、sessionId、OAuth 参数或个人标识。
- 好友邀请为只读入口，目标分始终“分享者填写 · 未经核验”。今日正式需服务器确认后进入既有每日入口，再由本人选身份/确认开局；旧题只开原序列练习。
- 非法日期、未来题、重复参数、越界分数、未知规则及网络失败不会偷偷换成今日题或扣次。OAuth 登录 hash 单独处理。
- 打开邀请与卡片暂停输入；关闭后回原结果。开始练习复用既有挑战存档替换确认、未知开局保护、补传日志保护与多页所有权，不改变经典记录。
