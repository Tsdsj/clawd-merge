## 边界与遗留项

- 真实OAuth2沿用用户确认，本轮不重复测试；真机软键盘和实际密码管理器仍待人工验收。
- 资源数据来自不同流量和进程状态的短时窗口，不能据此认定性能改善或回退。发布前backup内存/PIDs被Docker报告为0，该项不代表实际零占用，合计比较亦受影响。
- Cloudflare拒绝Python HTTP客户端；普通浏览器及默认curl健康访问可用。静态文件使用源站哈希验证。既有CSP阻止Cloudflare注入的统计脚本，未放宽防护。
- 一次性停机备份需要可写数据目录以重建WAL/SHM，数据库连接仍只读；已修正[操作清单](a07-release-preparation.md)，周期备份保持原有只读数据挂载。
- 已存在密码用户后应保留密码服务、密钥和当前数据。不能直接回退不识别密码账号的旧后端，也不能用旧备份覆盖发布后的新写入。
