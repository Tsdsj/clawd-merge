# 经典开局与每日身份显示修复

2026-10-03，依据用户线上验收截图修复。

## 根因与修改

- 经典客户端原本发送无 JSON body 的 POST /api/session。T10 增加的模式校验以 Request.body 是否非空判断是否解析 JSON；Cloudflare 的空 POST 也可能具有非空流，导致被判为非法 JSON。线上无凭据复现：空 POST 返回 400 bad_request，而 `{}` 返回预期的 401 unauthorized，说明失败发生在身份校验前。
- 后端仅在请求文本非空时解析 JSON，保留旧客户端空请求兼容；非空非法 JSON/null/数组仍拒绝，挑战模式仍拒绝进入经典接口。新客户端显式发送 `{mode:classic}`。
- 开局失败不再统一称为排行榜不可访问。保留失败类型并显示本局资格事实；排行榜 GET 成功不会补发已开始局的凭证或把本地局升级为在线局。
- 每日身份栏此前只拼接 `L · 昵称`。现与经典复用 player-identity 渲染，包含头像/游客色块、昵称/编号和 L 标记。相同身份刷新不重建头像；加载失败回退色块。

## 验证

- 新回归先复现空流 400 与客户端无 body，再修复；最终 npm test **168 项通过，0 失败**。
- 真实本地 workerd/D1 覆盖旧空 POST 与显式 classic JSON 开局，既有并发/回执/配额/清理回归通过。
- 真实浏览器隔离游客新开经典局显示“本局参与排名”；切每日显示统一游客卡及 3/3 机会。
- test/player-identity.html 使用实际共享渲染器：经典/每日头像成功加载且均18px，长昵称320px无溢出，失败图像回退，重复刷新复用原图片节点。
- 未代用户登录真实 LINUX DO，保留其现有身份与存档。已开始的本地局不会追溯上榜；新局按正常服务端签发结果决定资格。

发布结果在完成后补记；无数据库迁移。
